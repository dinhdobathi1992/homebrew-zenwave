Install & updates in three steps

Signed with a consistent self-signed certificate (ZenWave Local Signing) for verified in-app updates.

1

Install with Homebrew

Tap, trust the third-party cask tap, and install on macOS Apple Silicon:

brew tap dinhdobathi1992/zenwave
brew trust dinhdobathi1992/zenwave
brew install --cask dinhdobathi1992/zenwave/zenwave
2

Clear quarantine once & allow Keychain

Because releases are self-signed (not Apple-notarized), clear macOS Gatekeeper quarantine once after first install:

xattr -dr com.apple.quarantine /Applications/ZenWave.app

When macOS prompts for ZenWave Safe Storage in Keychain, click Always Allow.

3

Automatic in-app updates

Future releases download inside ZenWave and are verified by SHA256SUMS and leaf certificate pinning. The updater clears quarantine on the new bundle automatically before restarting.
