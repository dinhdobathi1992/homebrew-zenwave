Getting Started

Three steps from tap to automatic in-app updates

Signed consistently with ZenWave Local Signing so updates verify and clear quarantine for you.

01

Install via Homebrew

Tap, trust the third-party tap, and install on macOS Apple Silicon:

brew tap dinhdobathi1992/zenwave
brew trust dinhdobathi1992/zenwave
brew install --cask dinhdobathi1992/zenwave/zenwave
02

Clear quarantine once

Releases are self-signed (not notarized), so run once after your first install:

xattr -dr com.apple.quarantine /Applications/ZenWave.app

When macOS prompts for ZenWave Safe Storage in Keychain, click Always Allow.

03

Update inside the app

ZenWave checks GitHub Releases automatically, verifies SHA256SUMS and its pinned signing leaf certificate, clears quarantine on the new bundle, and swaps cleanly on restart.
